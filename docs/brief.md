# Product Brief — Soccer Talent Connection Platform

## Goal
Connect soccer players with agents and teams in Latin America. Players upload digital CVs; agents and teams search and discover talent effectively.

## §1 Player digital CV — required fields
- Personal info: name, age, height, weight, nationality, location
- Position(s) and play style (e.g., defensive midfielder, attacking winger)
- Career stats: goals, assists, appearances, minutes played, clean sheets
- Achievements: awards, tournaments, championships won
- Videos: game highlights, skill showcases, training sessions — linked from YouTube/Vimeo
- Team history: previous clubs, academies, experience level (amateur, semi-pro, professional)
- Availability status (open to trials / transfers)

## §2 Agent & team tools
- Shortlist players for follow-up
- Private notes on player profiles (visible only to the agent who wrote them)
- Saved searches (store filter combinations for reuse)

## §3 Search filters
Position(s) · age range · country/nationality · location/proximity · skill level (amateur, semi-pro, professional) · physical attributes (height, weight) · career stats (e.g., goals, assists) · availability for trials or transfers

## §4 Keyword search
Free-text search across profiles (e.g., "goleador", "especialista en tiros libres", "MVP liga juvenil").

## §5 Messaging
- Text-based direct messages between users
- File sharing: PDFs and images
- In-app and push notifications for unread messages
- Video calls: future upgrade, not v1

## §6 Membership plans
- **Basic (free):** standard profile, limited videos (1–2), standard search
- **Premium (paid):** up to 5 videos, priority visibility, full agent toolset
- Payments via Stripe (subscriptions), local LatAm currencies + USD; PayPal as a later addition

## §7 Admin dashboard
- Moderate profiles and uploaded content (approve / flag)
- Monitor user activity and performance metrics

## §8 Language
- Launch in Spanish (neutral Latin American)
- Architecture ready for additional languages later

## §9 Design
Modern, bold, professional. Dynamic colors (greens, blues, blacks). Media-focused: videos, images, and stats displayed prominently with minimalist surrounding UI. Smooth animations, hover effects, real-time notification updates. Intuitive navigation for creating profiles, searching, and messaging. Inspirations: LinkedIn, Tonsser, Behance.

## §10 Out of scope for v1
- Native mobile app (React Native) — responsive web only for now
- Direct video uploads (links only)
- Video calls
